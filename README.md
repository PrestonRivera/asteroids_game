# Asteroids game

I built this game using Pygame to solidy my sjills with object-oriented programming

## Play my version of the infamouse Asteroids game

### Installation 

1. Clone the repo

- `git clone https://github.com/PrestonRivera/asteroids_game.git`

2. CD into the project directory

- `cd user_path/asteroids_game`

3. Create a virtual enviroment

- `python -m venv venv`

4. Activate the virtual enviroment

- `source venv/bin/activate`

5. Install the dependicies

- `pip install -r requirements.txt`

6. Run the game

- `python3 main.py`
